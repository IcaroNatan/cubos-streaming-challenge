# 🎬 Cubos Streaming Challenge

Aplicação web de streaming desenvolvida como solução para um desafio de Front-end da **Cubos Academy**, simulando uma plataforma de filmes com integração à API do TMDB.

O projeto foi desenvolvido utilizando **HTML, CSS e JavaScript**, com foco em manipulação da DOM, consumo de APIs, eventos e criação dinâmica de elementos.

---

## 🚀 Funcionalidades

- 🎬 Catálogo de filmes obtidos através da API
- 🔎 Busca de filmes por título
- 📄 Paginação do catálogo
- ⭐ Exibição do "Filme do Dia"
- 🎞️ Modal com detalhes do filme selecionado
- 🌙 Alternância entre tema claro e escuro
- 📱 Interface responsiva
- 🔄 Atualização dinâmica do conteúdo através da DOM
- 🎥 Integração com trailers do YouTube

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- DOM
- Fetch API
- Async/Await
- API REST
- TMDB API
- Git

---

## 🔌 Integração com API

A aplicação utiliza a API disponibilizada pela Cubos Academy como proxy para acesso aos dados do **TMDB (The Movie Database)**.

Através da API são obtidas informações como:

- título dos filmes;
- imagens;
- avaliação;
- descrição;
- gêneros;
- data de lançamento;
- trailers;
- detalhes dos filmes.

## ⚙️ Como executar o projeto

### 1. Clone o repositório

```text
git clone https://github.com/IcaroNatan/cubos-streaming-challenge.git
```

### 2. Entre no diretório

```text
cd cubos-streaming-challenge
```

### 3. Instale as dependências

```text
npm install
```

### 4. Execute a aplicação

```text
npm start
```

A aplicação será disponibilizada localmente pelo servidor configurado no projeto.

## 🎨 Design

A interface foi desenvolvida com base no layout disponibilizado no desafio da Cubos Academy.

O projeto também possui suporte a tema claro e escuro e foi adaptado para diferentes tamanhos de tela.

## 🎓 Contexto do projeto

Este projeto foi desenvolvido como parte de um desafio de Front-end do módulo 7 da Cubos Academy.

O objetivo do desafio era desenvolver uma aplicação de streaming utilizando os conceitos estudados durante o módulo, incluindo HTML, CSS, JavaScript, manipulação da DOM e consumo de APIs.

A implementação apresentada neste repositório corresponde à minha solução para o desafio.
